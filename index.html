Bhow

Dog-care record and education preview for owners and carers.

Safety notice

Bhow content is educational only and is not veterinary diagnosis. If a dog has urgent symptoms (for example collapse, breathing distress, or suspected poisoning), contact a licensed veterinarian immediately.

Current release status

This site is a static project landing page. The FastAPI backend is still in preview and is not yet a public production service.

  • GitHub Pages publishes this static page only.
  • No user login or account features are provided on this page.
  • No medical or diagnostic claims are made for this preview.
